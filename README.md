# Cuaderno — app de notas libre y offline

100% Local y Privada: Funciona sin internet ni servidores externos. Tus datos se quedan en tu dispositivo
Modo Cuaderno Libre: Te permite colocar cajas de texto e imágenes en cualquier parte de la página, moverlas y redimensionarlas a tu gusto
Modo Texto Tradicional: Ideal para escribir de forma lineal y rápida
Diseño Oscuro: Inspirado en interfaces limpias, con tarjetas redondeadas y acentos sutiles 
(está app es una prueba lamento si hay fallos)
